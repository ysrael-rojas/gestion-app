# Glosario de analogías — traducir tecnicismos a la vida real

Léelo y reúsalo cuando expliques. La meta es que un dueño de negocio entienda sin saber programar.

| Término técnico | Analogía para explicarlo |
| --- | --- |
| Base de datos | El archivador de tu oficina: todo queda guardado en su lugar para encontrarlo después. |
| Tabla | Una gaveta del archivador (ej.: "Clientes", "Facturas"). |
| Campo / columna | Los renglones de una ficha (nombre, monto, fecha). |
| Servidor / backend | La trastienda del local: lo que el cliente no ve, pero hace que todo funcione. |
| API | El mesero: lleva tu pedido a la cocina y trae la respuesta. |
| Webhook | El timbre que suena y avisa cuando algo pasó (ej.: "llegó un pago"). |
| Pasarela de pago | La caja registradora con lector de tarjetas que cobra por ti. |
| Tokenización | Guardar el "apodo" de la tarjeta, nunca la tarjeta real. |
| Idempotencia | Que aunque toques el timbre dos veces, el cobro ocurra una sola. |
| Estado del documento | El semáforo de la deuda: "Por cobrar" / "Pagado" / "Vencido". |
| Recordatorio automático | Un despertador que avisa al cliente que debe pagar. |
| Nota de crédito | Un vale que descuenta parte de lo que te deben. |
| Conciliación bancaria | Cuadrar tu caja con el estado de cuenta que manda el banco. |
| Cuentas por cobrar (CxC) | La lista de quién te debe y cuánto. |
| Cuentas por pagar (CxP) | La lista de a quién le debes y cuándo le toca. |
| Mora | Los días de atraso de un cliente. |
| Reglas de acceso (RLS) | La regla que hace que cada negocio vea solo su propia carpeta. |
| Reintento | Volver a intentar un cobro que falló, sin cobrar doble. |
| Respaldo (backup) | Una fotocopia de tu archivador por si se pierde el original. |

Regla de oro: si aparece un término nuevo, tradúcelo con una analogía ANTES de seguir explicando.
