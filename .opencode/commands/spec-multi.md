---
description: Diseña una spec lista para ejecución multiagente (comandos de delegación, fases y modelos por unidad)
---

Carga el skill `spec-multi` (usa la herramienta skill con id `spec-multi`) y
diseña una spec orquestable multiagente para: $ARGUMENTS

Sigue el flujo del skill completo: contexto del proyecto, preguntas de
aclaración (incluido presupuesto de modelos), descomposición en fases con
matriz de traslape cero, asignación de modelos según la tabla del skill, y
guarda la spec en `specs/` con la sección "Orquestación multiagente". No
implementes nada; termina anunciando el path de la spec y el paso siguiente
(`/spec-impl`).
